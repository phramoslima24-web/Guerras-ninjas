# Como contribuir

1. Abra uma issue descrevendo o problema ou a melhoria.
2. Crie uma branch para sua alteração.
3. Mantenha a compatibilidade com Java 17, Minecraft 1.20.1 e Forge 47.x.
4. Execute `gradlew build` antes de abrir o Pull Request, quando o wrapper estiver disponível.
5. No Pull Request, explique o que mudou e como foi testado.

Não inclua arquivos gerados (`build/`, `.gradle/`, `run/`), logs com dados pessoais ou arquivos de configuração locais.
